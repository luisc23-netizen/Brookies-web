# Metadatos editables — Brookies

Admin > Contenido: título SEO de la portada, título y descripción para compartir, imagen Open Graph (subir o URL pública). Pulsar GUARDAR CONTENIDO.

La foto OG se muestra sin texto superpuesto. Sin foto se usa un diseño alternativo con logo tipográfico. Los metadatos se generan con valores de site_settings en el servidor.

No requiere SQL si site_settings tiene columnas key/value y admite claves nuevas (como en la versión actual).

Tras desplegar, validar /opengraph-image, HTML de la portada y Facebook Sharing Debugger. WhatsApp/Meta pueden conservar caché. El archivo de imagen debe estar disponible públicamente mediante HTTPS.
